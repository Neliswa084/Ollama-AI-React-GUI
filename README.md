# Ollama AI React GUI

A simple chatbot app built with React + TypeScript that talks to an AI model running locally with Ollama.

## Progress

- [x] Installed Ollama
- [x] Downloaded the `qwen2.5:0.5b` model (397 MB)
- [x] Created the React + TypeScript project with Vite
- [ ] Chat UI connected to Ollama
- [ ] Show response time and tokens per second
- [ ] System prompt and saved chat history

## Requirements

- Node.js
- Ollama with the model downloaded:

```
ollama pull qwen2.5:0.5b
```

## Run the app

```
npm install
npm run dev
```

Then open the link shown in the terminal.
